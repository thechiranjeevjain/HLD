# Repository Learning Order

<!-- project-catalog:learning-order:start -->

This is the **one canonical, exhaustive learning sequence** for the repository: **31 runnable learning units** (30 projects + 1 focused module). It is optimized for prerequisite flow and interview return on investment for senior Java/backend and electronic-trading roles.

Follow it from top to bottom. A dependency points to an earlier rank worth reviewing before continuing. ROI is interview value after accounting for transferability, frequency of discussion, and relevance to the target roles; it is not a second ordering.
